## Coverage and limitations
All six major sections (hero plus five numbered sections), full mobile vertical progression, desktop section navigation, mobile project swipe, six phone overlays, Escape and language toggle inspected. External destinations and PDF URLs inspected; no messages sent to reference author. Hover trajectories, touch physics, animation curves driven by JavaScript, exact particle response, external app handlers and every possible timing state cannot be claimed verified. Pointer hover was sampled using a drag from blank space. Email translation factor measured at approximately 0.30, social factor 0.35; implemented with 0.6s/0.4s cubic-bezier(.16,1,.3,1) transitions. The reference does not contain a contact form; the new form is an explicit requested addition. Skills detail text is a requested adaptation, not observed source behavior. Proprietary wallpapers, avatar, logo, project screenshots and personal copy are intentionally excluded.
